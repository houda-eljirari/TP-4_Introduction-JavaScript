# TP-4_Introduction-JavaScript

## Description

Ce projet contient les solutions du **TD JavaScript** du module **Technologies du Web & Web Sémantique**.
L'objectif du TP est de pratiquer les bases du langage JavaScript :

* variables
* fonctions
* structures de contrôle (if, while, for)
* tableaux
* manipulation de nombres
* affichage avec `console.log()`

Chaque exercice est implémenté dans un **fichier JavaScript séparé**.

# Comment exécuter le TP

1. Cloner ou télécharger le projet.

2. Ouvrir le fichier :

```
index.html
```

dans un navigateur web (Chrome ou Firefox).

3. Ouvrir la **console du navigateur** :

```
F12 → Console
```

4. Appeler les fonctions directement dans la console.
